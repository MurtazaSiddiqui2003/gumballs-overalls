# Gumballs & Overalls — redesign concept

A responsive, independent homepage redesign concept created by Eizora Labs for presentation purposes. It is not an official site and is not connected to the business's live website.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Before presenting or publishing
- Confirm exact address, hours, phone/email, social links, and store details with the owner.
- Confirm consignment split, item acceptance rules, appointment requirements, and seasonal dates.
- Replace temporary Unsplash photography with approved boutique/product photography.
- Obtain permission before publicly using the business name, logo, or presenting the concept as commissioned work.

Photography currently uses remote Unsplash image URLs as temporary placeholders.
